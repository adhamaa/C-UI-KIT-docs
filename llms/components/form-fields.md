# FormFields

Import: `import { FormFields } from '@adhamaa/ui-kit'`

Renders a form from a config: each entry becomes the matching RHF field.
Must sit inside `<FormProvider>`.

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `fields` (required) | `FormFieldsConfig` |  |  |
| `columns` | `number` | `1` | Columns at the top level. |
| `className` | `string` |  |  |
